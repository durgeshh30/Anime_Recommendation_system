🎌 Anime Recommendation System
This is a content-based Anime Recommendation System built using Python, Machine Learning, and Streamlit.
The app recommends similar anime based on the anime selected by the user.
This project was created to understand how recommendation systems work in Machine Learning using text similarity.

Website is Live on:- https://anime-recommendation-system-7mdk.onrender.com

github :- https://github.com/durgeshh30/Anime_Recommendation_system
_______________________________________
🔍 How it works
•	Anime descriptions are combined into a single tags column
•	Text data is converted into vectors using TfidfVectorizer
•	Cosine similarity is used to find similar anime
•	Recommendations are generated on demand to avoid high memory usage
•	Results are shown using a simple Streamlit web interface
________________________________________
📁 Dataset Info
The dataset contains:
•	id – TMDB anime/movie ID
•	title – Anime title
•	tags – Text data used for recommendations
Posters are stored offline (no live API calls), so the app works even when external APIs are blocked.
